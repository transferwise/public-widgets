Compact Calculator Widget

A space-saving calculator showing USD to MXN conversion in Spanish with hidden details. Perfect for sidebars, mobile layouts, or when space is limited.

🔧 Widget Configuration

  • Source Currency: USD (US Dollar)
  • Target Currency: MXN (Mexican Peso)
  • Default Amount: 1,500 USD
  • Language: Spanish (es)
  • Details: Hidden (compact view)
  • CTA Button: "Empieza" (Start)
  • Dimensions: 580px × 340px
  • Theme: Light

💡 Perfect For:

  • Spanish-speaking audiences targeting Mexico
  • Sidebars and smaller widget areas
  • Mobile-optimized layouts
  • Quick conversion tools without detailed breakdown

Implementation Code

1Add HTML Container 
<div id="wise-calc-widget">
    <!-- Calculator will be rendered here -->
</div>
2Add JavaScript Code (before closing </body> tag) 
<script type="text/javascript">
(function() {
  window.onload = function() {
    /* Change the variables below */
    var sourceCurrencyCode = "USD";
    var targetCurrencyCode = "MXN";
    var sourceAmount = 1500;
    var callToActionLabel = "Empieza";
    var hideCta = false;
    var hideDetails = true;
    var affiliateLink = "YOUR_TRACKING_LINK";
    var lang = "es";
    var width = "580px";
    var height = "340px";
    /* Do not modify the code below */
    var redirectUrlParams = encodeURIComponent("https://wise.com/");
    var redirectUrl = encodeURIComponent(affiliateLink + "?u=" + redirectUrlParams);
    var wiseIframeUrl =
      "https://wise.com/widget/calculator?sourceCurrencyCode=" + sourceCurrencyCode +
      "&targetCurrencyCode=" + targetCurrencyCode + "&amount=" + sourceAmount +
      "&cta=" + callToActionLabel + "&hideCta=" + hideCta + "&hideDetails=" + hideDetails +
      "&redirectUrl=" + redirectUrl + "&lang=" + lang + "&theme=light"
    var wiseIframe = document.createElement('iframe');
    wiseIframe.frameBorder = 0;
    wiseIframe.width = width;
    wiseIframe.height = height;
    wiseIframe.id = "wise-calc";
    wiseIframe.scrolling = "no";
    wiseIframe.setAttribute("allowtransparency", "true");
    wiseIframe.setAttribute("src", wiseIframeUrl);
    document.getElementById("wise-calc-widget").appendChild(wiseIframe);
  };
})();
</script>
3Key Settings for Compact View

Important Configuration Notes:

  • hideDetails: true - Reduces widget height and removes fee breakdown
  • height: "340px" - Optimal height for compact mode (vs 470px for full)
  • lang: "es" - Spanish language for Mexican peso audience
  • Replace YOUR_TRACKING_LINK with your affiliate link
