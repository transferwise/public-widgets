Static Comparison Table

Fixed comparison table for GBP to USD transfers (1500 amount). Users cannot change currencies or amounts - perfect for specific use cases.

The true cost of sending GBP to USD

🔧 Widget Configuration

  • Widget Type: tw-comparison-table (static)
  • Source Currency: GBP (British Pound)
  • Target Currency: USD (US Dollar)
  • Fixed Amount: 1,500 GBP
  • Language: English
  • Interactive: No - fixed currencies/amount
  • Providers: All available providers
  • Layout: Responsive, table-only format

Implementation Code

1Add HTML Link (Note: tw-comparison-table class) 
<a class="tw-comparison-table"
  href="https://wise.com/gb/compare/?sendAmount=1500&sourceCurrency=GBP&targetCurrency=USD"
  data-lang="en"
>The true cost of sending GBP to USD</a>
2Add JavaScript (before closing </body> tag) 
<script type="text/javascript">
(function() {
  window.onload = (function(d, s, id) {
    var js, fjs = d.getElementsByTagName(s)[0];
    if (d.getElementById(id)) return;
    js = d.createElement(s); js.id = id;
    js.src = "https://widgets.wise.com/widgets.js";
    fjs.parentNode.insertBefore(js, fjs);
  }(document, "script", "transferwise-wjs"));
})();
</script>
3Key Difference: tw-comparison-table

The key difference is using tw-comparison-table class instead of tw-comparison. This removes the currency selectors and locks the widget to your specified currencies and amount.
