Custom Comparison Widget

Spanish language comparison for GBP to USD with filtered providers. Shows how to customize language and limit providers for targeted audiences.

El verdadero costo de enviar GBP a USD

🔧 Widget Configuration

  • Widget Type: tw-comparison (full widget)
  • Source Currency: GBP (British Pound)
  • Target Currency: USD (US Dollar)
  • Default Amount: 850 GBP
  • Language: Spanish (es)
  • Provider Filter: 5 specific providers
  • Interactive: Users can change currencies/amounts
  • Layout: Responsive, auto-sizing

Implementation Code

1Add HTML Link with Custom Attributes 
<a class="tw-comparison"
  href="https://wise.com/gb/compare/?sendAmount=850&sourceCurrency=GBP&targetCurrency=USD"
  data-lang="es"
  data-providers="transferwise,paypal,starling-bank,xoom,western-union"
>El verdadero costo de enviar GBP a USD</a>
2Add JavaScript (before closing </body> tag) 
<script type="text/javascript">
(function() {
  window.onload = (function(d, s, id) {
    var js, fjs = d.getElementsByTagName(s)[0];
    if (d.getElementById(id)) return;
    js = d.createElement(s); js.id = id;
    js.src = "https://widgets.wise.com/widgets.js";
    fjs.parentNode.insertBefore(js, fjs);
  }(document, "script", "transferwise-wjs"));
})();
</script>
