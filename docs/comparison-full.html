Full Comparison Widget

Interactive comparison table with currency selectors showing GBP to EUR transfer options. Users can change amounts and currencies to compare providers dynamically.

The true cost of sending GBP to EUR

🔧 Widget Configuration

  • Widget Type: tw-comparison (full widget)
  • Source Currency: GBP (British Pound)
  • Target Currency: EUR (Euro)
  • Default Amount: 1,000 GBP
  • Language: English
  • Interactive: Users can change currencies/amounts
  • Providers: Multiple providers shown
  • Layout: Responsive, auto-sizing

Implementation Code

1Add HTML Link 
<a class="tw-comparison"
  href="https://wise.com/gb/compare/?sendAmount=1000&sourceCurrency=GBP&targetCurrency=EUR"
  data-lang="en"
>The true cost of sending GBP to EUR</a>
2Add JavaScript (before closing </body> tag) 
<script type="text/javascript">
(function() {
  window.onload = (function(d, s, id) {
    var js, fjs = d.getElementsByTagName(s)[0];
    if (d.getElementById(id)) return;
    js = d.createElement(s); js.id = id;
    js.src = "https://widgets.wise.com/widgets.js";
    fjs.parentNode.insertBefore(js, fjs);
  }(document, "script", "transferwise-wjs"));
})();
</script>
3Customize Your Settings

Change the currencies in the href URL and add optional parameters like data-affiliate-link with your affiliate URL.
